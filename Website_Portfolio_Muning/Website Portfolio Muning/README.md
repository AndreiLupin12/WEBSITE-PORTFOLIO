# Personal Portfolio Website Bundle

This package contains the modular source code for a developer portfolio.

## Files Included:
- `index.html`: Complete semantic HTML structure with all 7 portfolio sections.
- `style.css`: Pure CSS stylesheet containing responsive variables, layout utilities, and dark mode rules.
- `script.js`: Standalone JavaScript handling filtering, theme toggling, and interactive UI states.

## Setup Instructions:
1. Extract all files into a single project directory.
2. Open `index.html` in any web browser.
3. Edit placeholder texts in `index.html` to customize your personal credentials!
